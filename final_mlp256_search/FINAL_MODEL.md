# 当前全数据最终MLP模型

- 结构：21→256→128→1，共38,657个可训练参数。
- 输入：三栋楼各7个控制权重，合计21维；candidate_id不作输入。
- 输出：一个原始ramping单位的连续预测值；输出层为线性层，不强制非负。
- 隐藏层：ReLU，两个隐藏层之后均有Dropout=0.2；预测和寻优时eval关闭Dropout。
- 数据：全部2048条历史数据训练；输入与标签均使用全训练数据的均值和标准差，缓冲区随模型保存。
- 优化器：AdamW，初始学习率0.0028352644117458233，weight_decay=0.0003696879443531503。
- 训练：固定148轮，batch128，标准化MSE，梯度裁剪5；余弦T_max600、eta_min=初始学习率的1%，因此148轮结束时尚未降到调度最低值。
- 参数来源：30组TPE×内部三折验证；最终固定参数和内部最佳轮数中位数，再使用全数据重训。没有按最终训练误差继续加训。
- 随机种子：模型初始化20261029；独立批次打乱20361029。寻优种子仅影响控制权重搜索，不改变这个网络。
- 训练MAE：1.5643944030；用于选配置的内部验证MAE：4.7644191293。没有独立测试MAE，历史十折4.561498不是这个模型的测试成绩。
- 检查点：final_mlp256/results/full_20261030/model.pt。

- 搜索约束：3×7权重，每行非负且和1；目标仅为这个固定模型自身的预测ramping，不使用baseline代评或MAE/距离惩罚。

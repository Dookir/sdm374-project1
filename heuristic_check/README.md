# 最终MLP误差诊断与启发式寻优对照

同一固定最终模型，对比原10种子梯度/Adam/局部搜索与新增DE及PSO。每方法3种子、512种群、最多500代，使用相同起始种群，不把旧最优放入新方法初始种群；每个结果再用相同单起点SLSQP精修并分别报告原始/精修分数。不同算法的预算与收敛性质不同，不将结果当作严格复杂度排名或全局最优证明。最终保留原候选作为备选，不接受退步。

诊断只使用用户提供的两次真实评估反馈及原始数据/OOF，不调用真实评估器，不重新训练模型。结果记录diagnostics.json、comparison.csv、CPU审计和全部候选；不自动将新低预测作为新的真实改进提交。

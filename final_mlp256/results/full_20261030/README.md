结构为21→256→128→1，隐藏层ReLU；批量128、标准化MSE、clip5、余弦T_max600、最低学习率为初始值的1%。内部验证以MAE选择参数和检查点，最终轮数为最佳配置三个内部最佳轮数[148, 229, 148]的中位数；随后固定配置在全部数据从头训练，不再根据训练MAE追加轮数。

训练MAE用于记录全数据拟合效果；内部验证MAE用于调参，存在选择偏差，也不是独立测试成绩。此前冻结十折的OOF MAE **4.561498**来自另一轮交叉验证，只能作为训练方法参考，不能冒充这个全数据最终模型的测试MAE，不能据此宣称新模型泛化提升。

原十折模型、冻结包及给老师的ZIP未修改，原文件哈希核验通过。本次最终单模型单独保存，不覆盖十折中的任何一个。

## 文件与复现

- [model.pt](model.pt)：最终模型，包含全数据标准化缓冲区。
- [reproduction_recipe.json](reproduction_recipe.json)：精确配置、种子、轮数、环境版本、数据与源码哈希。
- [selection.json](selection.json)、[tuning/](tuning/)：30次配置及90次内部训练的完整选择依据。
- [training_predictions.csv](training_predictions.csv)：2048条训练预测，仅用于复算训练MAE。
- [audit.json](audit.json)：CPU审计；[normalization.json](normalization.json)：全数据标准化参数。

在仓库根目录、依赖已安装时，可在CPU加载 `neural_baseline.models.load`；预测输入必须按原CSV的21个权重列顺序，并使用float32。跨未知硬件从头重训不承诺参数逐位相同。原十折独立复现包继续用于老师逐折复现实验。
